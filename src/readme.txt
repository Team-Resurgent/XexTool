This package conatins Windows and Xbox360 versions of the xextool libraries which
should enable codebases that use them to work on both Windows and Xbox360.

The libraries are built with Visual Studio 2008.
The Windows libraries are set to use static runtime libraries (ie /MT and /MTd).
Both libraries are set to use the Multi-Byte Character Set.

The example dir contains the only other file besides these libraries required
to build the Windows exe file for XexTool. By looking at this source code you
should get a good idea of how to use the libraries. The headers may also contain
information on the various methods for each class and other relevant things.
